# NourishTrack — Mindful Calorie, TDEE & Weight Prediction App

Aplikasi web pencatat kalori harian, kalkulator BMI & TDEE otomatis (*Mifflin-St Jeor*), dan proyeksi berat badan 30 hari untuk pasangan (Suami & Istri) dengan arsitektur **GAS-PRO-API** (Frontend statis di GitHub Pages + REST API JSON di Google Apps Script).
